# ADR-005：Beta 首版小型资源使用 PostgreSQL `bytea`

- 状态：Accepted
- 日期：2026-08-23
- 范围：游戏包资源和发布校验

## 背景

Beta 需要游戏包导入、导出和权限控制。若首版直接引入对象存储，会增加新的权限、生命周期、备份和本地开发依赖；但无限制地把大文件写入数据库也会放大备份和复制成本。

## 决策

Beta 首版只允许受限的小型二进制资源写入 PostgreSQL `bytea`，资源元数据、摘要和授权关系同事务保存。单文件大小、总量和允许的 MIME 类型由配置限制，并在 API 与发布校验两侧执行。超过限制的资源暂不支持，不偷偷落到本地磁盘。

公开发布前根据真实资源规模重新评估 S3 兼容对象存储；若迁移到对象存储，PostgreSQL 仍保存资源元数据和权限事实。

## 后果

- 备份恢复测试必须覆盖资源配额和资源摘要。
- 导出包不能只导出二进制，还必须包含许可证、署名和内容摘要。
- 未来迁移对象存储属于独立变更，不能破坏已发布游戏版本的资源引用。
